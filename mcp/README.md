# AI Rule Learning — MCP Server

A personal MCP server that automatically learns guardrail rules from your AI
conversation history and injects them into future sessions.

## What it does

1. **Reads** your local Claude Code session files (`~/.claude/projects/`)
2. **Scrubs PII** (emails, home paths, tokens) before any data leaves your machine
3. **Uploads** new conversations to your private HF dataset
4. **Pulls back** your latest learned rules on demand
5. **Injects** them into Claude as a formatted system prompt block

## Installation

```bash
pip install ai-rule-learning-mcp
```

Or install from source:

```bash
git clone https://github.com/faju85/ai_rule_learning.git
cd ai_rule_learning/mcp
pip install -e .
```

## Configuration

Add to your `~/.claude/claude_desktop_config.json` (Claude Desktop) or
`~/.config/claude-code/mcp.json` (Claude Code):

```json
{
  "mcpServers": {
    "ai-rule-learning": {
      "command": "ai-rule-learning-mcp",
      "env": {
        "HF_TOKEN": "hf_your_write_token_here",
        "ARL_DATASET": "yourname/AI_Rule_Learning"
      }
    }
  }
}
```

You need:

- A [Hugging Face](https://huggingface.co) account
- A write token from <https://huggingface.co/settings/tokens>
- Your own `AI_Rule_Learning` dataset (clone from `vooom/AI_Rule_Learning`)

## Tools exposed to Claude

### `get_guardrail_rules`

Returns your active rules as a formatted block. Use it at the start of a
session to remind Claude of your personal guardrails:

> "Please load my guardrail rules before we start."

### `sync_sessions`

Exports new local sessions to your HF dataset and pulls back the latest rules:

> "Sync my sessions and update my rules."

## Workflow

````text
Weekly (or on session end):
  sync_sessions()
    → upload new conversations (PII-scrubbed)
    → open Space → Force Re-analyze All
    → new rules generated by Qwen2.5-72B

At session start:
  get_guardrail_rules()
    → Claude receives your rules as context
    → applies them throughout the session
```text
````
