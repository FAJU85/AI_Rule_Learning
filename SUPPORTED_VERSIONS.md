# Supported Versions

This project is evolving quickly. Support is focused on the latest release and the current `main` branch.

| Version        | Support status                               |
| -------------- | -------------------------------------------- |
| Latest release | Supported                                    |
| `main`         | Supported for development and upcoming fixes |
| Older releases | Best effort only                             |

## Python Support

The repository targets Python 3.11 for development and CI unless a package-specific file states otherwise.

## Reporting Compatibility Issues

Open a bug report and include:

- operating system,
- Python version,
- package version,
- command run,
- full error output with secrets removed.
